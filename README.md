# Money Escape

Онлайн-игра про деньги для друзей: начни с обычной работы, покупай активы и сбеги из денежной гонки первым.
Открой сайт, создай комнату и отправь друзьям код — играть можно с разных телефонов.

- `engine.js` — правила игры (чистые функции), тест: `node test/engine.test.mjs`
- `net.js` — онлайн через Firebase Realtime Database
- `database.rules.json` — правила базы
